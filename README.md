# 🛰️ LIMPE-MONITORA

### **Operational Fleet Monitoring System**

`INTERNAL PROJECT` · `FULL STACK` · `AUTOMATION` · `DATA` · `INFRASTRUCTURE`

</div>

> 🇧🇷 **Um sistema interno desenvolvido para apoiar o controle operacional através do cálculo e acompanhamento de atrasos da frota.**
>
> 🇺🇸 **An internal system developed to support operational control through fleet delay calculation and monitoring.**

<br>

<table>
<tr>

<td width="50%" valign="top">

### 🎯 O problema | The Problem

**🇧🇷**

O acompanhamento de atrasos depende de informações provenientes do sistema de rastreamento contratado.

O projeto foi criado para transformar essas informações em um fluxo mais estruturado para **controle, processamento e acompanhamento operacional**.

**🇺🇸**

Delay monitoring depends on information obtained from the contracted tracking system.

The project was created to transform that information into a more structured workflow for **operational control, processing, and monitoring**.

</td>

<td width="50%" valign="top">

### 💡 A solução | The Solution

**🇧🇷**

Uma aplicação full stack que combina:

* Coleta automatizada
* Processamento de dados
* API REST
* Banco de dados
* Cache
* Autenticação
* Dashboard
* Deploy automatizado
* Observabilidade

**🇺🇸**

A full-stack application combining:

* Automated collection
* Data processing
* REST API
* Database
* Shared cache
* Authentication

* Observability

</td>
